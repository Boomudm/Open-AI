# Assets

Source artwork and other non-runtime design assets.

- `neo/` contains original Neo brand artwork used by generation scripts.
- `neo/readme-banner.png` is the colorful hero banner embedded in the root `README.md` (PNG — GitHub-safe).
- `neo/readme-banner.svg` is the vector source for that banner.
- Runtime web assets live under `web/public/` so Next.js can serve them directly.
