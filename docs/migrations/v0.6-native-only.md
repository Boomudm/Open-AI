# Migration Guide: v0.6 Native-Only

## Overview

This migration removes the RAGFlow backend and makes the native ingest pipeline the sole backend.

## Configuration Changes

Set `INGEST_BACKEND=native` in your environment. The RAGFlow configuration keys
(`ragflow_api_url`, `ragflow_api_key`, `ragflow_dataset_id`) are no longer recognized.

## Breaking Changes

- RAGFlow ingest backend removed
- `ingest_backend_resolver.py` deleted
- Legacy synthesis functions removed from facade
